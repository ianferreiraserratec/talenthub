# Talent Hub Serratec

Aplicação interna do Serratec para operar o pool de talentos, clientes, vagas e processos do Talent Hub em Google Apps Script, com Google Sheets como banco operacional.

O desenvolvimento acontece na branch `homologacao`. A branch `main` representa a versão estável destinada à produção.

> A implementação funcional e a documentação técnica são desenvolvidas em `homologacao` antes da promoção para `main`.
